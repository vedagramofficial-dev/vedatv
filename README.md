# VedaTV

VedaTV — современный IPTV-плеер для Android. Приложение не содержит встроенных каналов: пользователь самостоятельно добавляет свои M3U или M3U8-плейлисты.

## Возможности

- Добавление нескольких плейлистов по URL
- Автоматическое обновление списка каналов
- Категории и поиск по каналам
- Избранные каналы
- Просмотр через Media3 / ExoPlayer
- Современный интерфейс на Jetpack Compose и Material 3
- Автоматическая сборка APK через GitHub Actions

## Сборка

GitHub Actions автоматически собирает debug-APK при каждом push в ветку `main`.
Готовый файл появится во вкладке **Actions → Build VedaTV APK → Artifacts** под именем `vedatv-debug-apk`.

## Важно

VedaTV является только плеером. Пользователь отвечает за законность добавленных им плейлистов и трансляций.
